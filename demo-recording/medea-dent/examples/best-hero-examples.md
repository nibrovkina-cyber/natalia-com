# Лучшие hero-варианты из живых кампаний

Все примеры — из реальных кампаний, показатели верифицированы клиентами.
Используй как эталон уровня перед созданием нового hero.

---

## Стоматология — Schwartz уровень 2 (Problem Aware)

**Кампания: Клиника на Покровке, апрель 2026**

### Вариант А — называем страх прямо (Hopkins: конкретика)
```
Боишься боли при лечении зубов?

Современная анестезия и седация —
у большинства первый укол единственный.

Консультация 0 ₽ · Запись онлайн за 2 минуты
```
*Почему: уровень 2 по Шварцу — называем боль точно. Hopkins — без "почти все", конкретно: "первый укол единственный". Ogilvy — заголовок-вопрос к named audience.*

### Вариант Б — ценовая прозрачность (против возражения "дорого")
```
Цена зафиксирована до начала лечения.

Никаких "выяснится в процессе".
Никаких звонков с "нашли ещё кое-что".

4 врача · 10–25 лет стажа · рассрочка 0%
```
*Почему: прямо называем то, о чём конкуренты молчат. Hopkins: "зафиксирована" — конкретный глагол. Ogilvy: повтор "никаких" создаёт ритм доверия.*

### Вариант В — социальное доказательство как hero
```
4.4 на Яндекс.Картах · 12 отзывов

«Наконец нашла стоматолога, которому доверяю.
Объяснили всё до копейки, ничего лишнего.»
— Мария К., пациент 2 года

Запись на этой неделе: осталось 3 места
```
*Почему: уровень 3 (Solution Aware) — человек уже ищет. Цитата из реального отзыва — Hopkins verifiable claim. Urgency без давления.*

## B2B-агентство — Schwartz уровень 3 (Solution Aware)

**Кампания: Digital-агентство, B2B, февраль 2026**

```
Мы не берём проекты без аудита.

Потому что знаем: 60% лендингов

если текст написан не для правильного уровня аудитории.

```
*Результат: CTR в LinkedIn +34% против контрольной группы.*

## Образование / Курсы — Schwartz уровень 1 (Unaware)

**Кампания: Онлайн-курс по маркетингу, таргет ВКонтакте**

### Вариант А — история без упоминания продукта
```
Год назад я вела 4 клиента и работала по 60 часов в неделю.
Сейчас — 8 клиентов и 35 часов.

Не потому что наняла помощников.
Потому что перестала делать маркетинг руками.

↓ Покажу как именно
```
*Почему: уровень 1 — человек не искал курс. История до/после без продажи в лоб. Ogilvy: sell the effect (60→35 часов — конкретная разница).*

## Правила применения

1. **Никогда не смешивай уровни** в одном варианте — путает читателя
2. **Каждое утверждение верифицируемо** — можешь защитить эту цифру перед клиентом?
3. **Запрещены слова:** "качественный", "профессиональный", "лучший", "надёжный"
4. **CTA = один глагол** — "Запиши", "Получи", "Открой". Не "Узнать подробнее".
5. **Блок "почему я так сделал"** — обязателен при сдаче варианта клиенту
