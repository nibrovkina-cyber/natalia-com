# MEDEA Dent — проект в Claude Code

## Клиент
Стоматология MEDEA Dent, ул. Покровка, д. 1/13с1, Москва (м. Китай-город).
Открыты пн–вс 9:00–22:00. Основана в 2004 году.

## Навигация папок
- `_foundations/` — методология: Шварц, Огилви, Хопкинс, голос бренда
- `context/` — brand-memory.json с данными клиники
- `SOPs/` — стандартные процедуры работы (research, content)
- `examples/` — лучшие примеры hero-вариантов из живых кампаний
- `skills/` — скиллы агентов (создаём в процессе работы)

## Правила
- Не использовать [UNVERIFIED] данные из brand-memory в копирайтинге
- Все утверждения — верифицируемые факты (Hopkins rule)
- Тон: профессиональный + тёплый, без медицинского жаргона
- ЗАПРЕЩЕНО: "элитная", "лучшая клиника", "опытные специалисты" без числа

## Юридическое
Реклама медуслуг требует строки: «Имеются противопоказания. Необходима консультация специалиста.»
