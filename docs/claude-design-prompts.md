Используй эти промты после того как закончишь с Pricing. По одному за раз.

## Промт 2 — Case Study (MEDEA Dent)

```
Контекст: у нас уже есть cases/medea-dent.html в handoff.
Это хороший SaaS-кейс, но нужно поднять до редакционного
уровня — как разбор в Kinfolk или editorial case study
у Pentagram / Collins / Porto Rocha.

Продукт: страница-кейс в галерее natashabrovkina.com.
Бизнес-клиент: стоматология в Москве, переделанная через
AI-команду. Основная функция страницы — быть социальным
доказательством ("вот что AI сделал с реальным бизнесом").

Цель: страница которую можно показать клиенту и он скажет
"это сделал AI?? я хочу такое же для моей клиники".

Структура из handoff осталась:
— Nav (как на pricing)
— Breadcrumbs: Кейсы / MEDEA Dent
— Hero: бейдж ниши + h1 + метрики
— Drag-to-compare slider (главная фишка)
— "Что AI исправил" — 5 пунктов с методологией
— "Методология" — 3 принципа O/S/H с применением
— CTA

Но подача — **другая**:

1. HERO ВМЕСТО БЕЙДЖЕЙ И МЕТРИК
   Не нужно "Стоматология / Москва / дата" горизонтально.
   Вместо этого: одна гигантская цифра (например "↑ 3,4×")
   Playfair 200px на cream-фоне, под ней мелко "заявок в
   месяц — после AI-редизайна". Остальная информация
   (дата, ниша, город) — микро-текстом сбоку, не главное.

2. DRAG-SLIDER КАК ЦЕНТРАЛЬНАЯ СТАТУЯ
   Занимает почти весь viewport (85vh). Без карточки-контейнера.
   Фулскрин. Единственная видимая интерактивность на странице.
   Drag-handle — не просто 2px полоска с кружком, а
   массивный visual element с градиентом или subtle pattern.

3. SCROLL-REVEAL СТОРИЛАЙН
   После слайдера — вертикальный narrative как статья:
   — "До" (короткое эссе о проблеме, 2-3 абзаца, типографика
     как NYT Morning newsletter)
   — "Что изменили" (5 пунктов не как список, а как нумерованные
     micro-essays, каждый с маленьким куском HTML-кода или
     мини-скриншотом старого/нового)
   — "Почему это работает" (методология Ogilvy/Schwartz/Hopkins
     — каждый принцип с цитатой автора и фото его книги/
     оригинального рекламного объявления из архива)

4. ТИПОГРАФИКА УРОВНЯ ЖУРНАЛА
   — Начальная буква раздела увеличена (drop cap) как в книгах
   — Цитаты классиков оформлены крупным italic в центре колонки
   — Номера разделов римскими цифрами (I, II, III) мелко сбоку
   — Line-height 1.7+ для текста-эссе (не 1.55 SaaS)

5. CTA НЕ КАК CTA
   Не кнопка "Хочешь такое? →" внизу.
   Вместо: "— Наталья Бровкина" курсивом (как подпись автора),
   и ниже один абзац "если хочешь обсудить свой кейс, пиши
   в Telegram @NATASHABROVKINA". Всё. Как в конце
   авторской статьи, не sales landing.

Ограничения:
— Navy / gold / cream / mint палитра
— Playfair + Inter + JetBrains Mono
— portrait.png — единственное фото
— Drag-slider должен работать (кнопки 50/50, auto-demo,
  пины на before при position ≥ 88%)
— Mobile responsive — slider обязательно работает на touch

Output: один файл cases/medea-dent-v2.html.
Не делай 3 варианта. Один сильный.
```

## Промт 3 — Studio (главный инструмент)

```
Контекст: у нас есть designs/studio.html — основной рабочий
инструмент продукта. Пользователь вставляет URL конкурента,
нажимает "Запустить", видит как 16 AI-агентов работают,
получает готовый премиум-лендинг.

Текущий дизайн — правильный SaaS layout (split-screen 420+1fr,
форма слева, preview справа). Это работает. Но для
YouTube-ролика и впечатления "это не ChatGPT, это
режиссёрский инструмент" — нужно больше характера.

Референсы другого уровня:
— Arc Browser (arc.net) — tech с личностью, anti-corporate
— Linear.app changelog — quality > quantity
— Replit ghostwriter — код как искусство
— v0.dev от Vercel — generative AI с отчётливым эстетическим
  голосом
— Figma's blog — минимализм + subtle motion

Архитектура остаётся из handoff:
— Top chrome 56px navy-2
— Split grid 420px + 1fr
— Form pane: URL input, niche chips, brief textarea,
  3 mode cards, submit button
— Preview pane: 4 tabs, domain label, viewport switch,
  frame container
— Loader overlay: progress + 16 agent list
— Success: banner + action-bar с 4 кнопками

Что поднять на editorial-tier:

1. EMPTY STATE ПРЕВЬЮ КАК ART-PIECE
   Сейчас в handoff: центрированный 120×120 art-block с
   двумя пульсирующими кольцами + буква N.
   Хочу: больше. Целая композиция на весь preview pane:
   — Крупная Playfair-цитата типа "Первое впечатление —
     единственное" (Огилви, 1963)
   — Под цитатой 16 мелких точек-меток в две сетки 8×2,
     каждая — имя агента (серая opacity 0.3), при hover
     показывается задача агента
   — Внизу еле видимая monospace-строка "ожидает брифа..."
   Это **обучает** о продукте до того как пользователь
   начнёт работать.

2. LOADER КАК ТЕАТРАЛЬНАЯ СЦЕНА
   Сейчас: progress bar + список агентов. Работает.
   Хочу: добавить **центральный акт**. Пока агенты работают
   внизу в узкой строке, в центре preview-pane крупно
   появляются **цитаты** связанные с текущим активным
   агентом:
   — Ogilvy-агент: "Headline is 80% of your ad budget"
   — Schwartz-агент: "Before we write, we must know who we're
     writing for"
   — Hopkins-агент: "Advertising is salesmanship in print"
   — и т.д.
   Смена цитаты синхронна со сменой агента (3.2 сек). 20+
   цитат в пуле, рандом.

3. FORM PANE — РЕДАКЦИОННЫЕ АКЦЕНТЫ
   URL input: вместо простого `https://` prefix сделай
   подсказку "Вставь URL конкурента который хочешь превзойти"
   микро-италиком над полем. После ввода URL она исчезает.
   Niche chips: не pill-кнопки. Вместо — маленькие
   tab-underlined как табы в inDesign (steel underline для
   неактивного, gold для активного, без фона).
   Mode cards: пусть будут карточки, но **сильнее различимы**:
   каждая своего характера (Solo — почти минимализм, Team —
   diamond-плотный, Parallel — split effect). Хочется
   чтобы они выглядели как три разные личности.

4. ACTION-BAR ПОСЛЕ УСПЕХА
   Сейчас: 4 кнопки в float-баре. Хочу убрать symmetry.
   Вместо 4 одинаковых кнопок:
   — "Опубликовать" — крупная gold кнопка слева (primary)
   — Три остальные (Скачать, Правки, Ещё) — text-links
     с иконками, compact, справа
   Visual hierarchy.

5. ТИПОГРАФИКА СМЕНА
   Добавь JetBrains Mono более агрессивно: не только для
   timer и domain-label, а для **всех UI-элементов где есть
   число или технический элемент**: "1 агент · ~30 сек" на
   mode cards, "N/16" в loader, "16 агентов · 52 сек"
   после успеха. Это создаёт ощущение **IDE для маркетинга**,
   а не веб-формы.

6. "РАССКАЗ" БЕЗ КНОПОК ВНИЗУ
   После того как лендинг сгенерирован, в preview появляется
   iframe. Под ним (в preview pane, не на action-bar) —
   одна строка мелким italic:
   "Готово за 52 секунды. 16 агентов. Методология Ogilvy/
   Schwartz/Hopkins. Это — итерация 1 из бесконечности."
   Пропагандирует что можно нажать "Ещё вариант" и получить
   другое. Без давления.

Ограничения:
— Split-screen structure остаётся
— 16 агентов остаются (можно обогатить их задачи)
— Navy/gold/cream/mint
— Работает без JavaScript как минимум empty state и form
  (progressive enhancement)
— Mobile: form sticks, preview stacks below

Output: один файл studio-v2.html.
```

## Заметка

После каждой итерации Claude Design:
1. Открой файл в браузере — смотри как это выглядит
2. Если не нравится какой-то элемент — **не переделывай всё сразу**.
   Итерируй микро-промтом: "Измени только hero, остальное не трогай"
3. Когда финальная версия устраивает — скидывай zip сюда

Я порчу в React, подключу Framer Motion для анимаций, использую next/font, сохраню все design tokens из globals.css.
