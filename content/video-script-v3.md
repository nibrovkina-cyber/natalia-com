# Видео-сценарий v3 — «Уволила маркетинг-команду. Зарабатываю больше»

**Длина:** 10:00 (плотный)
**Формат:** screen-share 88% + talking head 12%
**Аудитория:** ОДНА — владелец стоматологии/салона/школы/клиники в РФ, у которого **есть лендинг, нет заявок, нет времени** на найм маркетолога
**Цель:** 1 000 в waitlist + 200 GitHub-stars за 30 дней + 1-2 Personal-клиента
**Главная виральная фишка:** drag-slider до/после в 0:00-0:05 без речи + новый TOP-title с провокацией

> ⚠️ **Это v3 — переписан под Scenario C из аудита (`pre-recording-audit-2026-04-27.md`).** Одна аудитория, один главный агент в фокусе (Copy), методология в одном плотном блоке, остальные 15 агентов упомянуты вскользь. Прогноз vs v2: 15-50K просмотров вместо 6-20K.

> 📁 **Использует:** `public/demo/clinic-demo-brand-memory.json` (вымышленная Клиника Дента — fallback если MEDEA-consent не получен) ИЛИ реальный MEDEA-кейс если consent есть. См. instructions ниже.

## STOCK-ОТВЕТЫ НА 5 ТИПОВЫХ КОММЕНТАРИЕВ

### «А чем это лучше чем просто ChatGPT?»

```
Тремя вещами:

1. Методология. Каждый ответ заканчивается блоком «почему я так
   сделал» с конкретными правилами Огилви/Шварца/Хопкинса. ChatGPT
   так не делает по умолчанию.

2. Brand Memory. ChatGPT забывает между сессиями. Мой JSON-шаблон
   подгружается в каждый чат — AI помнит твой бизнес во всех 16 ролях.

3. Студия. Читает URL клиентского сайта через Firecrawl, верстает
   готовый HTML-лендинг. ChatGPT этого не делает.

Скачай GitHub-репо, попробуй один SKILL.md в Claude.ai. За 5 минут
увидишь разницу.
```
