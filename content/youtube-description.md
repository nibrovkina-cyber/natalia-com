## Stock-ответы на типовые комментарии (готовь копипасту)

### "Это же ChatGPT"
```
Отличный вопрос. Разница в трёх вещах:
1) ChatGPT не читает сайты автоматически — я вставляю URL, Firecrawl забирает контент сам
2) ChatGPT забывает ваш бизнес между сессиями — у меня Brand Memory применяется ко всем 16 агентам
3) ChatGPT не объясняет почему так написал — а мой инструмент даёт блок "почему" с методологией Шварца/Огилви/Хопкинса в каждом ответе

Открой инструмент, попробуй оба инструмента на одной задаче — увидишь разницу за минуту
```

### "А сколько стоит?"
```
Free: open-source GitHub-репо (свой Anthropic-ключ ~$5/мес)
Self-Serve: 2 990 ₽/мес — hosted UI без возни с ключами, безлимит, Brand Memory
Personal: 49 000 ₽ разово — 30 дней лично со мной, 3 места в месяц

Для сравнения: маркетинг-команда в штат — 380 000 ₽/мес ФОТ.
```

### "А для [моего бизнеса] работает?"
```
Инструмент работает с любым бизнесом, который можно описать словами или у которого есть сайт. Ресторан, клиника, магазин, B2B-услуги — без разницы.

Вставь URL → через минуту увидишь результат. Бесплатно.
```

### "Подскажите код/как сделано/какой AI"
```
Под капотом — Claude (от Anthropic), Firecrawl для чтения сайтов, Next.js для интерфейса. Промпты пишу сама, в них зашиты Schwartz/Hopkins/Ogilvy.
```

### "Помогите мне настроить [что-то сложное]"
```
Индивидуальная настройка — формат Agency от 49 900 ₽ разово + абонентка. Пиши в личку: [email/telegram]
```

### "Вы просто переупаковали ChatGPT"
```
Если открыть капот — да, API-вызовы к Claude. Как у любого AI-продукта в мире. Вопрос что сверху — методология, 16 специалистов с памятью, интерфейс который читает сайты. Это и есть продукт.

Продукт — не модель. Продукт — то что вокруг модели.
```

### "Скачал HTML. Куда его заливать?"
```
Два варианта:
1) Тильда, Bitrix, WordPress — вставить как "Произвольный HTML" блок
2) Отдельный сайт — загрузить файл на хостинг (Beget, REG.RU, Timeweb) или задеплоить на Vercel/Netlify бесплатно
```

### "А можно без ИИ — просто заказать у вас?"
```
Можно. Пиши в личку [email/telegram], расскажу про индивидуальные проекты.
```
