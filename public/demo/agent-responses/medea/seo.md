## 2. Яндекс SEO — поведенческие факторы

**ИКС (Индекс качества сайта)** — для медицины критичен ≥ 100. Что влияет:
1. **Время на сайте** — нужны лонгриды про услуги (1500+ слов с подзаголовками)
2. **Глубина просмотра** — связки между страницами через релевантные ссылки («Лечение кариеса → Эстетическая стоматология → FAQ боли»)
3. **Возврат пользователей** — записанные через сайт пациенты возвращаются → SEO растёт

**Регистрация в Яндекс.Бизнес** — обязательно. Это даёт:
- Карточку в Яндекс.Поиске
- Snippet в Картах
- Возможность отвечать на отзывы публично

**Schema-разметка обязательная для медицины:**

```json
{
  "@context": "https://schema.org",
  "@type": "Dentist",
  "name": "MEDEA Dent",
  "address": { "@type": "PostalAddress", "streetAddress": "ул. Покровка, 1/13с1", "addressLocality": "Москва" },
  "telephone": ["+7-910-498-17-72", "+7-495-628-08-53"],
  "openingHours": "Mo-Su 09:00-22:00",
  "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.4", "reviewCount": "12" },
  "priceRange": "₽₽"
}
```

## 4. GEO-оптимизация (AI-поиск ChatGPT, Perplexity, Google AI Overview, Gemini)

**Цель:** когда пациент спросит у Claude или ChatGPT «куда пойти лечить зубы на Покровке без боли» — упоминается MEDEA Dent.

### Что делает AI-цитирование вероятным

1. **FAQ-блок с прямыми ответами в начале абзаца** (для Featured Snippets и AI):
   ```
   Q: Сколько стоит имплантация в MEDEA Dent?
   A: Имплантация в MEDEA Dent стоит от [N] ₽ с гарантией [N] лет, доступна рассрочка 0%.
   ```
2. **Структурированные списки** (AI цитирует bullet'ы охотнее чем абзацы)
3. **Конкретные цифры в текстах** — «4 врача», «4.4★», «20 лет в практике» — AI любит верифицируемые данные
4. **Markdown-структура HTML**: `<h2>`, `<h3>`, `<ul>` для AI-краулеров
5. **Файл `/llms.txt`** в корне сайта (новый стандарт для AI):
   ```
   # MEDEA Dent
   > Стоматология на Покровке (Москва) с 2004 года. 4 врача со стажем 10-25 лет.
   - Адрес: Покровка 1/13с1, метро Китай-город
   - Часы: пн-вс 9:00-22:00
   - Услуги: имплантация, лечение кариеса, эстетика, ортодонтия
   - USP: 0₽ первая консультация, рассрочка 0% на импланты
   - Рейтинг: 4.4★ на Яндекс.Картах (12 отзывов)
   ```

**🧠 Почему я так сделал:**

- **Ogilvy** — для каждого запроса предложен **специфический заголовок** + meta. Никаких «современная стоматология». Каждое объявление называет конкретный сегмент пациента.
- **Schwartz** — разные H1 под разные уровни: коммерческий (Most Aware) → сразу оффер; информационный (Problem Aware) → история и боль. Один сайт ≠ одна аудитория.
- **Hopkins** — Schema + цифры + ИКС-метрики — всё verifiable. Я не сказала «улучшим SEO», я расписала точные действия с временем и приоритетом.
- **Brand voice** — никаких «лучший выбор для жителей Покровки», только факты с числами.
- **Чего я НЕ делал** — не закидала ключевыми словами «как ChatGPT» (Wordstat-объёмы я пометила как [оценка], потому что точных нет до запуска wordstat-runner). Не дала универсальный SEO-чек-лист на 50 пунктов — ICP клиника не сможет такое выполнить, нужен фокус на 7 действиях.
